表 8 7 类测量流程失效、可能导致的错误解释与修正后需要的证据

| 观察到的测量工具问题 | 可能导致的错误解释 | 修正后需要的证据 |
|---|---|---|
| DVWA 认证返回 HTTP 200 登录页 | 把从未到达受保护模块的请求当作有效攻击测试 | 会话 setup、安全级别读取并核对、认证模块检查 |
| Prometheus 终止影响后续请求 | 把不活跃服务当作后续规则的保护 | 每种测试配置执行前重新初始化后端；把破坏性效果与测试前健康分离 |
| 冷启动或无效的测试准备状态 | 把传输/就绪失败当作规则结果 | 显式 readiness/测试准备结果；保留失败尝试 |
| mlflow 复用旧对象 UUID | 把过期对象引用当作有效合法任务 | 从当前测试准备响应提取标识符 |
| 审计事件仅按 URI 对齐 | 把另一个请求的拒绝归给当前请求 | 唯一请求标识连接到完整审计事务 |
| 保存的响应文本被裁剪或只读了一部分 | 从残缺证据声称“不存在”或“成功” | 原始字节、长度、哈希、完整解码内容、完整性与错误字段 |
| WAF 响应阶段中断发生在 HTTP 200 已发送之后 | 声称请求被阻止或保证未泄露 | 分开记录响应中断与观察到的泄露谓词 |

注：在这些情形下，对记录的计算可以完全正确，据此得出的安全结论仍然错误。
