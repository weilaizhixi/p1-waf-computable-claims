- 值差异合计 **16**；输出类型名的回答单元合计 **4**；存在差异的回答单元合计 **20**，影响 **19 个任务**。
- 没有模型–任务对在两个提示条件下都出现**值差异或以类型名代替字段值**；T360 在 neutral 下有两个路由差异，故 20 个回答单元对应 19 个任务。**例外**：gpt6luna × T222 在两个条件下都有**缺失字段**（2 个缺失字段回答单元），但缺失字段不属于这 20 个存在差异的回答单元；不要用“两个条件都无差异”覆盖它。
- **不得**把“两个条件都无差异”解释为提示修复了错误：每个条件只有一个选中响应，顺序未随机化，历史运行包含任务重建。
- **不得**把某个路由的零计数解释为在其他任务或未来调用上无错误。

## D. 4930 个回答单元的互斥分类

| 结果类别 | 回答单元数 |
|---|---:|
| 数值或其他值差异 | 16 |
| 以类型名代替字段值 | 4 |
| 请求字段缺失 | 2 |
| 完整答案，值经声明规则强制转换后正确、但类型有偏差 | 747 |
| 完整答案，值与类型均符合 | 4161 |
| **Total** | **4930** |

- 2 个缺失字段均来自 gpt6luna 对 T222 的两个条件：返回 `n_withnonnull_error` 而非 `n_with_nonnull_error`；总请求字段存在。归档评分器把必需字段视为缺失，不把未输出值计为错误值。
- 2 个缺失字段回答单元**同时**带有“不完整对象”诊断；这是同两个回答单元，**不是额外两个失败**。
- 747 个仅格式偏差的例子：整数值字符串按声明规则读为整数；**不得**把它们重新计为数值错误。
- 主分析没有因输出上限被截断的选中响应；历史上不可用的 provider 记录单列，不加入本分区。

## J. 测量流程失效链与有界修复

| 观察到的仪器问题 | 可能导致的错误解释 | 修正后需要的证据 |
|---|---|---|
| DVWA 认证返回 HTTP 200 登录页 | 把从未到达受保护模块的请求当作有效攻击测试 | 会话 setup、安全级别读取并核对、认证模块检查 |
| Prometheus 终止影响后续请求 | 把不活跃服务当作后续规则的保护 | 每种测试配置执行前重新初始化后端；把破坏性效果与测试前健康分离 |
| 冷启动或无效的测试准备状态 | 把传输/就绪失败当作规则结果 | 显式 readiness/测试准备结果；保留失败尝试 |
| mlflow 复用旧对象 UUID | 把过期对象引用当作有效合法任务 | 从当前测试准备响应提取标识符 |
| 审计事件仅按 URI 对齐 | 把另一个请求的拒绝归给当前请求 | 唯一请求标识连接到完整审计事务 |
| 保存的响应文本被裁剪或只读了一部分 | 从残缺证据声称“不存在”或“成功” | 原始字节、长度、哈希、完整解码内容、完整性与错误字段 |
| WAF 响应阶段中断发生在 HTTP 200 已发送之后 | 声称请求被阻止或保证未泄露 | 分开记录响应中断与观察到的泄露谓词 |

**补充修复**：保留原始 Host 端口并对齐测试准备请求与普通请求转发，消除了历史 WordPress 重定向与 Jenkins crumb 失败；这些旧失败因此**不支持**针对默认规则的误报主张。DVWA 公共说明页的响应侧截断被记录为响应损坏，而不是重新标记为完整的请求侧 403 阻断。
